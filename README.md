# LeadFlow – Lead Management System

LeadFlow is a Django-based Lead Management System designed to manage leads, counselors, courses, students, trainers, batches, fees, attendance, certifications, and enrollments from a single platform.

## Features

- User authentication and authorization
- Admin and Counselor role-based access
- Lead management
- Course management
- Counselor management
- Trainer management
- Batch management
- Student management
- Subject management
- Enrollment management
- Fee and installment management
- Payment history
- Attendance management
- Certification management
- OTP-based forgot password
- Dashboard with management information
- PostgreSQL database integration
- Responsive Bootstrap interface

## Technologies Used

- Python
- Django
- PostgreSQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git
- GitHub
